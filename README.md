# 2022 年高教社杯全国大学生数学建模竞赛 C 题：古代玻璃制品建模

本仓库保存 2022 年高教社杯全国大学生数学建模竞赛 C 题“古代玻璃制品的成分分析与鉴别”的完整建模编程交付，包括数据预处理、统计检验、分类与聚类、未知样品鉴别、成分关系网络、可复现代码、机器可读结果、论文图表和验收报告。

> 本仓库用于数学建模学习、结果复核和方法交流。仓库内结论受赛题样本规模、缺失结构和模型适用域限制，不应直接用于真实文物鉴定。

## 项目内容

建模流程覆盖四个赛题问题：

1. 分析玻璃类型、纹饰和颜色与表面风化的关系，估计风化前后的成分变化，并给出风化样品的反事实未风化成分。
2. 建立高钾玻璃与铅钡玻璃的分类模型，并探索两类玻璃内部可能存在的亚类。
3. 使用问题 2 冻结后的模型识别 A1–A8 未知样品，同时评估预测不确定性和适用域。
4. 在组成数据框架下分析不同类别玻璃化学成分之间的关系及差异网络。

流程特别处理了组成数据闭合约束、显式零与缺失值的区别、同一文物多采样点造成的信息泄漏、分组交叉验证、Bootstrap 稳定性、置换检验和模型冻结等问题。

## 交付概览

- 199 个交付文件（不含本机虚拟环境和缓存），总计约 4.9 MB。
- 64 个正式结果 CSV、35 张论文可用 PDF 图、18 条跨问题结论—证据索引。
- 固定主随机种子 `202208`，统一参数见 `config/config.json`。

- 所有已知错误、未触发备用流程和模型限制见 `reports/ERRORS_AND_LIMITATIONS.md`。

## 目录结构

```text

├─ code/       # 预处理、7 个子任务、一键运行、哈希与验收脚本
```

建议首先阅读：

## 环境安装

推荐使用 Python 3.14，并在仓库目录中创建独立虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
```

若精确锁定版本与本机 Python 不兼容，可改用：

```powershell
python -m pip install -r requirements.txt
```

## 运行方式

完整流程由以下命令启动：

```powershell
python code\run_all.py
```

注意：当前交付目录不包含受赛题来源约束的原始 `附件.xlsx` 和 `C题.pdf`。完整重跑时，代码默认按下面的相对布局读取它们：

```text
父目录/
├─ C题/
│  ├─ 附件.xlsx
│  └─ C题.pdf
└─ 本仓库目录/
```

仓库已包含由正式运行生成的规范化数据、结果、模型、日志和图表，因此无需重跑也可直接复核本次交付。输入文件哈希记录在 `results/00_audit/input_hashes.json`。

## 结果与复现说明

正式结果以 `results/` 内 CSV/JSON 为准。`results/99_summary/claim_evidence.csv` 将主要结论映射到具体证据文件，避免仅凭图形目测或文字转述。图表数据位于 `figures/source_data/`，可用于复核或重新绘图。

`.venv/`、`.matplotlib/`、`__pycache__/` 等本机环境和缓存不会提交到 GitHub；它们不是建模成果，可通过依赖清单重新生成。
